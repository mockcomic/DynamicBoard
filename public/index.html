All functions must be wrapped with {}

Example: {tillDate(12,25,2025)} days till Christmas

  • tillDate(mm,dd,yyyy)
    Returns how many days till the date specified. For yearly repeating events it counts to the next yearly occurrence.
  • birthday(name,mm,dd,yyyy,daysAhead)
    Shows a countdown inside the days-ahead window and switches to Happy Birthday on the day.
  • todayDate()
    Returns the current date.
